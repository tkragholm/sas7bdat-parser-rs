## R CMD check results

One WARNING and one NOTE, both explained below.

### WARNING: `checking compiled code` finds `_abort`

```
File 'fastsas/libs/fastsas.so':
  Found '_abort', possibly from 'abort' (C)
```

This symbol comes from the Rust standard library, not from any code in this package.
Rust's `std` references `abort` on its panic path, and every Rust package linking
`std` carries the reference; it is present in the packages already on CRAN that are
implemented in Rust.

It is not reachable from normal operation. The R-facing entry points are generated by
extendr, which wraps every call in `catch_unwind` and converts a Rust panic into an R
condition, so a fault surfaces as an R error and the session continues. The package
does not call `abort`, `exit` or `std::process::abort` anywhere.

Silencing it would require building with `panic = "abort"`, which is precisely what
extendr must not do — it needs unwinding for the `catch_unwind` above. The alternative
is a `no_std` core, which is not feasible for a package that memory-maps files and
uses threads.

## Bundled Rust sources

CRAN build machines have no network access, so the package's Rust dependencies are
bundled as source in `src/rust/vendor.tar.xz` (2.7 MB), which `src/Makevars` unpacks
and builds against with `cargo --offline`. Nothing is downloaded during installation.

The copyright holders and licences of all bundled crates are listed in
`inst/AUTHORS`, which is generated from the vendored tree itself so that it cannot
describe a different dependency set from the one shipped. Every crate's own licence
text ships inside the archive alongside its sources.

The archive contains only what a build reads: test suites, benchmarks, example data
and repository scaffolding are removed before packing, and the pruned tree is
test-built offline to confirm nothing needed was removed.

## Toolchain

`SystemRequirements` declares `rustc >= 1.89`, which is the highest `rust-version`
declared by any bundled crate. The package deliberately ships no
`rust-toolchain.toml`: such a file would make rustup attempt to download a specific
toolchain, which cannot work on a machine without network access.
