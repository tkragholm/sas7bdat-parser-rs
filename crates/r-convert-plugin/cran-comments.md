## R CMD check results

One WARNING and three NOTEs, all explained below.

### WARNING: `checking compiled code` finds `_abort`

```
File 'fastsasconvert/libs/fastsasconvert.so':
  Found '_abort', possibly from 'abort' (C)
```

This symbol comes from the Rust standard library, not from any code in this package.
Rust's `std` references `abort` on its panic path, and every Rust package linking
`std` carries the reference; it is present in the packages already on CRAN that are
implemented in Rust.

It is not reachable from normal operation. The R-facing entry points are generated by
extendr, which wraps every call in `catch_unwind` and converts a Rust panic into an R
condition, so a fault surfaces as an R error and the session continues. The package
does not call `abort`, `exit` or `std::process::abort` anywhere.

Silencing it would require building with `panic = "abort"`, which is precisely what
extendr must not do — it needs unwinding for the `catch_unwind` above.

### NOTE: pragmas suppressing diagnostics

```
'src/rust/vendor/zstd-sys/zstd/lib/zstd.h'
'src/rust/vendor/zstd-sys/zstd/lib/dictBuilder/divsufsort.c'
```

These are upstream files from the zstd C library, bundled unmodified by the
`zstd-sys` crate and used for Parquet compression. The pragmas are the zstd
maintainers' own; we do not patch upstream C sources, since diverging from them would
be worse for correctness and for tracking security fixes than carrying this note.

### NOTE: source file not terminated with a newline

```
src/rust/target/release/build/zstd-sys-*/out/flag_check.c
```

This file does not ship in the package. It is written into the build directory at
compile time by `zstd-sys`'s build script, which uses it to probe whether a compiler
flag is accepted. It exists only because `R CMD check` inspects the source tree after
the build has run.

## Bundled Rust sources

CRAN build machines have no network access, so the package's Rust dependencies are
bundled as source in `src/rust/vendor.tar.xz`, which `src/Makevars` unpacks and builds
against with `cargo --offline`. Nothing is downloaded during installation.

The archive is larger than a package with no compiled dependencies would be. It
contains the Apache Arrow and Parquet writers and the zstd codec, which are what the
package exists to provide — it converts SAS files to Parquet without loading them into
R. It has been reduced as far as is possible without dropping functionality: test
suites, benchmarks, example data and repository scaffolding are stripped before
packing, and one dependency was replaced with a local implementation specifically
because it pulled in 18 MB of platform bindings for a directory walk. The pruned tree
is test-built offline to confirm nothing needed was removed.

The copyright holders and licences of all bundled crates are listed in
`inst/AUTHORS`, which is generated from the vendored tree itself so that it cannot
describe a different dependency set from the one shipped. Every crate's own licence
text ships inside the archive alongside its sources.

## Toolchain

`SystemRequirements` declares `rustc >= 1.89`, which is the highest `rust-version`
declared by any bundled crate. The package deliberately ships no
`rust-toolchain.toml`: such a file would make rustup attempt to download a specific
toolchain, which cannot work on a machine without network access.
